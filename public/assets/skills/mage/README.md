# Mage skill icons

Seven existing Mage skill icons downloaded from the Perfect World International icon archive on PWpedia and converted to PNG without resizing. The source images are 32 x 32 pixels.

| Project file | Project skill | Perfect World icon |
| --- | --- | --- |
| `fire-mark.png` | Marca do Fogo | [Pyrogram](https://pwi.fandom.com/wiki/File:Pyrogram.png) |
| `sudden-spring.png` | Fonte Repentina | [Gush](https://pwi.fandom.com/wiki/File:Gush.png) |
| `stone-rain.png` | Chuva de Pedra | [Stone Rain](https://pwi.fandom.com/wiki/File:Stone_Rain.png) |
| `phoenix-wings.png` | Asas da Fênix | [Will of the Phoenix](https://pwi.fandom.com/wiki/File:Will_of_the_Phoenix.png) |
| `flaming-storm.png` | Tempestade Flamejante | [Emberstorm](https://pwi.fandom.com/wiki/File:Emberstorm.png) |
| `sand-storm.png` | Tempestade de Areia | [Sandstorm](https://pwi.fandom.com/wiki/File:Sandstorm.png) |
| `moving-earth.png` | Terra Móvel | [Distance Shrink](https://pwi.fandom.com/wiki/File:Distance_Shrink.png) |

The English skill names are matched to the project skills by their Perfect World effects. The icons remain unintegrated; Phaser still uses the current placeholders until the later art integration task.

The icon artwork belongs to Perfect World and its respective rights holders. The images were retrieved from the [PWpedia Wizard Skill Icons archive](https://pwi.fandom.com/wiki/Category:Wizard_Skill_Icons) on 2026-09-27. No claim of ownership is made over the game artwork.
